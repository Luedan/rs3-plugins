## Dialogue Transcript


### In Varrock

- **Shopkeeper:** Hello, bold adventurer. Can I interest you in some swords?
- [Menu]: Select an option
  - [Choice]: Yes, please.
    - (opens=Varrock Sword Shop)
  - [Choice]: No, I'm okay for swords right now.
    - **Player:** No, I'm okay for swords right now.
    - **Shopkeeper:** Come back if you need any.

### In New Varrock

- **Shopkeeper:** Hello. You're a bold one. <br>Can I interest you in some swords?
- [Menu]: Select an option
  - [Choice]: Yes, please.
    - (opens=New Varrock Sword Shop)
  - [Choice]: No. Goodbye.
    - **Shopkeeper:** Come back if you need any.
