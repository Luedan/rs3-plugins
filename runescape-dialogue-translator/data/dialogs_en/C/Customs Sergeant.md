## Dialogue Transcript


### Standard dialogue

- (Condition: If not started Rocking Out:)
  - **Customs Sergeant:** Zzzzzzzzzzzzzzzzzzz.
  - **Player:** Ahem.
  - **Customs Sergeant:** Push off, I'm busy.
  - **Player:** Okay.
  - **Customs Sergeant:** Now!
- (Condition: If partially completed Rocking Out:)
  - (see|Rocking Out)
- (Condition: If partially completed Pieces of Hate:)
  - (see|Pieces of Hate)
- (Condition: If partially completed Rocking Out and after he arrested the player once:)
  - **Customs Sergeant:** You? How did you escape?
  - **Player:** With awesome daring and courage.
    - (Condition: If carrying items:)
      - **Customs Sergeant:** Store all of that no-doubt stolen gear, so I can send you back where you belong.
      - **Player:** Okay, okay, keep your cap on!
    - (Condition: If not carrying items:)
      - **Customs Sergeant:** Right, let's see if you can get out this time.
