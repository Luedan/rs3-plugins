# Camp dweller

- **Original Wiki Page**: [Transcript:Camp dweller](https://runescape.wiki/w/Transcript%3ACamp%20dweller)
- **Letter**: `C`

---

## Dialogue Transcript

- *Each Camp dweller has slightly different dialogue:*
  - *First Camp dweller*
    - **Player:** Nice day, isn't it?
    - **Camp dweller:** Yes.
  - *Second Camp dweller*
    - **Player:** Hello!
    - **Camp dweller:** Hello.
  - *Third Camp dweller*
    - **Player:** Nice place you have here!
    - **Camp dweller:** It is indeed.
  - *Fourth Camp dweller*
    - **Camp dweller:** I've heard about all the things you did for us!
    - **Player:** I was happy to help.
    - **Camp dweller:** And I'm happy that you helped us! Maybe now this place can be a bit more cheerful again!
  - *Fifth Camp dweller*
    - **Camp dweller:** I'd rather be left alone, outerlander.
