## Dialogue Transcript


### Ferry

- ((Upon using ferry for the first time at a given location:))
  - You can now be ferried to this destination: [Well of Souls/Ed's Boatyard/Main Plaza/Sunken Market/Haunt on the Hill].
  - ((Repeated in a popup:))
    - You can now be ferried to this destination: [Well of Souls/Ed's Boatyard/Main Plaza/Sunken Market/Haunt on the Hill].
    - (continue)
  - (continue)
- ((With only one ferry location unlocked:))
  - You'll need to unlock a second ferry destination before you can use this service.
- ((With multiple ferry locations unlocked:))
  - ((The following is shown in an interface titled "SELECT AN OPTION":))
    - Select ferry destination
      - 1. Well of Souls (ritual site).
        - (continue)
      - 2. Ed's Boatyard (boat tours).
        - (continue)
      - 3. Main Plaza (Soul Supplies).
        - (continue)
      - 4. Sunken Market (bank).
        - (continue)
      - 5. Haunt on the Hill (dark portal).
        - (continue)
  - {{Qact|The interface closes. The screen fades out and back in. The player is standing next to the ferryman at the chosen destination.}}

### Previous destination


#### Without having used the ferry system

- You have not yet used the ferry system to have a previous destination set.

#### Having used the ferry system

- {{Qact|The screen fades out and back in. The player is standing next to the ferryman at the previously chosen destination.}}

### Return trip


#### Without having used the ferry system

- You have not yet used the ferry system to have a ferry to return to.

#### Having used the ferry system

- {{Qact|The screen fades out and back in. The player is standing next to the ferryman at the ferry system location used previously.}}
