- **Letter**: `D`

---

## Dialogue Transcript


### Repairing

- (Condition: If there is not any construct parts:)
  - You need some construct parts to attempt a repair.
- (Condition: If there is an incorrect construct part:)
  - (removes=spare construct part)
  - You try to force the part in, but it doesn't fit and explodes!
- (Condition: If there is a correct construct part:)
  - (removes=spare construct part)
  - You attach the missing part to the construct.
