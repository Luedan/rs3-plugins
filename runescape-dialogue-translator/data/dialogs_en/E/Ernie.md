## Dialogue Transcript


### In Varrock


#### Standard dialogue

- **Ernie:** Hello! I'm Ernie the urn collector!
- **Player:** Hello, I'm Player.
- **Ernie:** Do you have any urns?
- [Menu]: Select an Option{{anchor|original}}
  - [Choice]: What are urns?

    - **Ernie:** You don't know what an urn is? Inconceivable!
    - **Ernie:** Urns are big, magical pots. You keep them in your bag, and they collect scraps and wastage while you perform activities that are related to that urn.
    - **Ernie:** For example, a fishing urn collects guppies while your attention is on larger catches.
    - **Ernie:** Once it's full, you can teleport the urn to me!
    - **Ernie:** Sweet little guppies...
    - (initial|original)
  - [Choice]: Why would I want to give you any urns?
    - **Player:** Why would I want to give you any urns?
    - **Ernie:** Why wouldn't you, more to the point?
    - **Player:** No, why would I want to send you my full urns?
    - **Ernie:** Oh...for a reward, of course!
    - **Ernie:** You see, I've seen a lot in my lifetime; I have some tricks of the trade to share with you.
    - **Ernie:** You send me an urn, I reward you with know-how regarding the skill type of your urn. Some might call it...gaining experience.
    - **Player:** That's a strange way to phrase it.
    - (initial|original)
  - [Choice]: How do I make urns?
    - **Player:** How do I make urns?
    - **Ernie:** Oh, just use some soft clay on the pottery wheel and then fire the results in the pottery oven downstairs. Urns are big, so you'll need two batches of clay per urn.

    - **Ernie:** If you get stuck, just show me where you've got to and I'll give you some advice. You can also hand full urns to me in person, if you'd prefer.

#### Using items on Ernie


##### Clay

- **Ernie:** That clay is far too hard. You'll need to mix it with water before you have clay suitable for making urns.

##### Soft clay

- **Ernie:** Ah, lovely clay! You'll need two batches of this, then you can use a potter's wheel to make a beautiful urn!

##### Unfired urn

- **Ernie:** Ah, this urn hasn't been fired! You'll need to take that to a pottery oven. Feel free to use the one downstairs.

##### Fired urn

- **Ernie:** This urn has been fired. You can trade it now, or if you want to use it, you'll need to add a rune to it.
  - *Prayer urn*
    - **Ernie:** This is a prayer urn, so you'll need an air rune to activate it.
  - *Fishing urn*
    - **Ernie:** This is a fishing urn, so you'll need a water rune to activate it.
  - *Cooking urn*
    - **Ernie:** This is a cooking urn, so you'll need a fire rune to activate it.
  - *Divination urn*
    - **Ernie:** This is a divination urn, so you'll need a mind rune to activate it.
  - *Farming urn*
    - **Ernie:** This is a farming urn, so you'll need a nature rune to activate it.
  - *Mining urn*
    - **Ernie:** This is a Mining urn, so you'll need an earth rune to activate it.
  - *Smelting urn*
    - **Ernie:** This is a smelting urn, so you'll need a fire rune to activate it.
  - *Hunter urn*
    - **Ernie:** This is a hunter urn, so you'll need a mud rune to activate it.
  - *Woodcutting urn*
    - **Ernie:** This is a woodcutting urn, so you'll need an earth rune to activate it.
  - *Runecrafting urn*
    - **Ernie:** This is a runecrafting urn, so you'll need some pure essence to activate it.

##### Activated urn

- **Ernie:** I see you've activated this urn with a rune.
  - *Prayer urn*
    - **Ernie:** This is a prayer urn, so you should slay some demons to start filling the urn with ashes.
  - *Fishing urn*
    - **Ernie:** This is a fishing urn, so you should take it with you when you go fishing to start collecting guppies.
  - *Cooking urn*
    - **Ernie:** This is a cooking urn, so you should keep it with you when you are cooking to start collecting food scraps.
  - *Divination urn*
    - **Ernie:** This is a divination urn, so you should take it with you when you harvest memories to start collecting fragments.
  - *Farming urn*
    - **Ernie:** This is a farming urn, so you should take it with you when you harvest your plants to start collecting cuttings.
  - *Mining urn*
    - **Ernie:** This is a Mining urn, so you should take it with you when you go mining to start collecting ore slivers.
  - *Smelting urn*
    - **Ernie:** This is a smelting urn, so you should keep it with you when you are smithing to start collecting metal scraps.
  - *Hunter urn*
    - **Ernie:** This is a hunter urn, so you should take it with you when you go hunting to start collecting iotas.
  - *Woodcutting urn*
    - **Ernie:** This is a woodcutting urn, so you should take it with you when you go woodcutting to start collecting woodchips.
  - *Runecrafting urn*
    - **Ernie:** This is a runecrafting urn, so you should take it with you when you bind rune essence to start collecting remnants.

##### Partially-filled urn

- **Ernie:** This urn isn't ready yet. Please come back when it's full.

##### Full urn

- **Ernie:** A lovely full urn! Let me take that off your hands.
- **Ernie:** You know, you can teleport your full urns straight to me if you're too busy to come back here.
- You hand Ernie the urn. You gain [number] [Skill] XP.
