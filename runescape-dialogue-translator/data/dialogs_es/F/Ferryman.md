# Ferryman

- **Original Wiki Page**: [Transcript:Ferryman](https://runescape.wiki/w/Transcript%3AFerryman)
- **Letter**: `F`
- **Language**: Español (Entidades, ítems y ubicaciones preservados en inglés)

---

## Dialogue Transcript


### Ferry

- ((Al utilizar el ferry por primera vez en un lugar determinado:))
  - Ahora puedes ser transportado a este destino: [Well of Souls/Ed's Boatyard/Main Plaza/Sunken Market/Haunt on the Hill].
  - ((Repetido en una ventana emergente:))
    - Ahora puedes ser transportado a este destino: [Well of Souls/Ed's Boatyard/Main Plaza/Sunken Market/Haunt on the Hill].
    - (continue)
  - (continue)
- ((Con solo una ubicación de ferry desbloqueada:))
  - Deberá desbloquear un segundo destino de ferry antes de poder utilizar este servicio.
- ((Con múltiples ubicaciones de ferry desbloqueadas:))
  - ((Lo siguiente se muestra en una interfaz titulada "SELECCIONE UNA OPCIÓN":))
    - Selecciona el destino del ferry
      - 1. Pozo de las Ánimas (lugar ritual).
        - (continue)
      - 2. Ed's Boatyard (paseos en barco).
        - (continue)
      - 3. Plaza Principal (Suministros del Alma).
        - (continue)
      - 4. Mercado Hundido (banco).
        - (continue)
      - 5. Haunt on the Hill (portal oscuro).
        - (continue)
  - (Action: La interfaz se cierra. La pantalla se desvanece y vuelve a aparecer. el player está parado junto al barquero en el destino elegido.)

### Previous destination


#### Sin haber utilizado el sistema de ferry

- Aún no has utilizado el sistema de ferry para establecer un destino anterior.

#### Habiendo utilizado el sistema de ferry

- (Action: La pantalla se desvanece y vuelve a aparecer. el player está parado junto al barquero en el destino previamente elegido.)

### Return trip


#### Sin haber utilizado el sistema de ferry

- Aún no has utilizado el sistema de ferry para tener un ferry al que regresar.

#### Habiendo utilizado el sistema de ferry

- (Action: La pantalla se desvanece y vuelve a aparecer. el player está parado junto al barquero en la ubicación del sistema de ferry utilizada anteriormente.)
