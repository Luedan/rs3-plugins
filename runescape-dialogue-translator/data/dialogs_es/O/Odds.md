## Dialogue Transcript


### Talk to

- **Player:** Aquí tienes todo tipo de basura.
- **Odds:** Basura... para ti. Tesoro... para los demás.
- **Player:** ¿Dónde encontraste estas cosas?
- **Odds:** Camino... ruina... bolsillo.
- **Odds:** Todas las cosas... quieren dueño.
- **Player:** ¿Incluso esta olla rota?
- **Odds:** La olla está rota... todavía contiene semillas.
- **Player:** Nunca se han dicho palabras más sabias.
