- **Smuggler:** Esa es una roca rica en mineral metálico. Puedes fundirlo en barras de metal en el horno usando la habilidad Smithing. También se puede utilizar como ingrediente secundario para las bolsas de invocación de Bloodrager.

#### Barras

- **Smuggler:** Esa es una barra de metal. Puedes usarlo con un martillo sobre un yunque para crear armaduras y armas cuerpo a cuerpo usando tus habilidades de herrería.

#### Sucursales

- **Smuggler:** Esas son ramas de madera. Puedes usar un yesquero y tus habilidades para hacer fuego para quemarlos y usar el fuego resultante para cocinar. También puedes usar un cuchillo y tu habilidad de emplumar para crear arcos sin cuerdas, bastones básicos, flechas y trampas a partir de ellos, o usarlos como ingrediente secundario para crear bolsas de invocación de Deathlinger.

#### Cuerdas de arco

- **Smuggler:** Esa es la cuerda de un arco. Conéctelo a un arco sin cuerda para crear un arma a distancia utilizable.

#### Textiles

- **Smuggler:** Es un tejido elaborado a partir de plantas crudas. Gírelo en una rueca para crear tela. También puedes usarlos como ingrediente secundario al crear bolsas de invocación de Stormbringer.

- **Smuggler:** Eso es tela. Usa aguja e hilo para convertirlo en una armadura de mago u orbes mágicos, usando tus habilidades en la elaboración. También puedes usarlo para eliminar el veneno de las armas.
