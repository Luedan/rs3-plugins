## Dialogue Transcript


### At the Falador Farm

- **Sarah:** Hola. ¿Le puedo ayudar en algo?
- [Menu]: Selecciona una opción
  - [Choice]: ¿Qué estás vendiendo?
    - (opens=Sarah's Farming Shop)
  - [Choice]: ¿Puedes darme algún consejo agrícola?
    - **Player:** ¿Puedes darme algún consejo agrícola?
    - **Sarah:** Sí, pregúntale a un jardinero.
  - [Choice]: ¿Puedes decirme cómo usar el telar?
    - **Player:** ¿Puedes decirme cómo usar el telar?
    - **Sarah:** Bueno, en realidad es mi telar, pero no me importa que lo uses, si quieres. Puedes utilizarlo para tejer sacos y cestas en los que poner verduras y frutas.
    - [Menu]: Selecciona una opción
      - [Choice]: ¿Qué necesito para tejer sacos?
        - **Player:** ¿Qué necesito para tejer sacos?
        - **Sarah:** Bueno, los mejores sacos están hechos de fibras de yute. Puedes cultivar yute tú mismo en un huerto de lúpulo. Yo diría que unas cuatro fibras de yute deberían ser suficientes para tejer un saco.
        - **Player:** Gracias, es muy amable.
      - [Choice]: ¿Qué necesito para tejer cestas?
        - **Player:** ¿Qué necesito para tejer cestas?
        - **Sarah:** Bueno, las mejores cestas están hechas con ramas jóvenes cortadas de un willow tree. Necesitarás una willow tree muy joven, de lo contrario las ramas habrán crecido demasiado gruesas para poder tejer. Sugiero cultivar el tuyo propio.
        - **Sarah:** Puedes cortar las ramas con un par de tijeras de podar estándar. Probablemente necesitarás unas seis ramas de sauce para tejer una cesta completa.
        - **Player:** Gracias, es muy amable.
      - [Choice]: Gracias, es muy amable.
        - **Player:** Gracias, es muy amable.
  - [Choice]: Estoy bien, gracias.
    - **Player:** Estoy bien, gracias.
