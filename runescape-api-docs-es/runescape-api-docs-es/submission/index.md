# Submission

Plugins are distributed by [Mod.io](https://mod.io/g/runescape), which contains the library of all plugins that are available to players. To upload plugins to this platform you will need to create a Mod.io account, which will contain the information associated with the plugins that you create. You may wish to create this account with a name that you are already known by in the RuneScape community, but this is not required.

## Guías Clave para la Publicación

* [Plugin guidelines](guidelines.md) - For what a plugin is allowed to do.
* [The submission process](process.md) - For how to submit your plugin.

## Requisitos Legales

All plugins are required to include several statements in their description on Mod.io in order to comply with all relevant legal requirements, whether set by Jagex or any other legal authority. These requirements are detailed [here](process.md#required-description-sections).

### EULA

All plugins are required to agree to the [Jagex End User License Agreement (EULA)](https://legal.jagex.com/docs/terms/eula) in order to be approved. This is done by including a statement in the plugin's description during the submission process that links back to this document.

### Adecuación Legal (Reino Unido) requirements

Plugins that send information to a destination without [full or relevant partial UK adequacy](adequacy.md) (e.g. EU / EEA, Canada and Japan) are required to provide additional information to Jagex in regards to data protection. If your plugin only sends information within the UK or EEA, or does not send information at all, then your plugin needs only to include a statement to confirm this, and no further action is required.
