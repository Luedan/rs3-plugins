# Directrices Oficiales para Plugins

Jagex ha establecido una serie de principios fundamentales para asegurar que los plugins mejoren la experiencia del jugador sin perjudicar la integridad del juego ni otorgar ventajas competitivas desleales.

---

## Principios Fundamentales

### 1. No Automatización (Cero Bots / Macros)
* Los plugins **NUNCA** deben realizar clics automáticos, mover el ratón ni simular entradas de teclado que el usuario no haya efectuado directamente.
* La regla de oro es: **1 acción humana = 1 acción de juego**.

### 2. No Ocultar Información Crítica
* Los plugins no deben ocultar intencionadamente avisos de peligro, indicaciones de ataque en combate ni avisos de seguridad del juego.

### 3. Privacidad y Seguridad
* Está estrictamente prohibido recopilar contraseñas, tokens de sesión o datos personales de los jugadores.
* Las peticiones HTTP deben ser transparentes y limitarse a los servicios necesarios (ej. consultar precios de mercado en APIs públicas).

### 4. Respeto al Arte y la Experiencia Visual
* Los plugins de interfaz deben integrarse armoniosamente en el estilo visual de RuneScape.

---

## Política sobre Inteligencia Artificial (IA)

Se permite el uso de herramientas de IA para asistir en la redacción del código de los plugins; sin embargo:
* El desarrollador humano es **100% responsable** del código final subido a Mod.io.
* El código debe ser limpio, comprensible y estar documentado.
* No se admitirán plugins generados masivamente o de baja calidad ("spam").
